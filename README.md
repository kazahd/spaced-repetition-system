## 1. Запуск бэкенда (FastAPI)

### Шаг 1.1. Открыть терминал и перейти в папку backend

```cmd
cd C:\МИРЭА\СПО\курсач\spaced-repetition-system\backend
```

### Шаг 1.2. Активировать виртуальное окружение

```cmd
venv\Scripts\activate
```

В начале строки появится `(venv)`.

### Шаг 1.3. Запустить сервер

```cmd
python -m uvicorn app.main:app --reload
```

**Результат:** Сервер запустится на `http://127.0.0.1:8000`

**Проверка:** Открыть в браузере `http://127.0.0.1:8000/docs` — должна открыться документация Swagger.

## 2. Запуск фронтенда (Vue.js)

### Шаг 2.1. Открыть **новый** терминал

Бэкенд остаётся запущенным в первом терминале.

### Шаг 2.2. Перейти в папку frontend

```cmd
cd C:\МИРЭА\СПО\курсач\spaced-repetition-system\frontend
```

### Шаг 2.3. Запустить сервер разработки

```cmd
npm run dev
```

**Результат:** Фронтенд запустится на `http://localhost:5173`

**Проверка:** Открыть в браузере `http://localhost:5173` — должна открыться страница входа.

## 4. Если что-то не работает

| Проблема | Решение |
|----------|---------|
| `uvicorn not found` | Не активирован venv или не установлены зависимости → `venv\Scripts\activate` → `pip install -r requirements.txt` |
| `npm not found` | Node.js не установлен → скачать с [nodejs.org](https://nodejs.org) |
| `module 'app' not found` | Не та папка → проверьте, что вы в `backend/` |
| Порт 8000 занят | Остановить процесс или сменить порт: `uvicorn app.main:app --reload --port 8001` |
| CORS ошибка | Проверьте, что бэкенд запущен и в `main.py` есть `allow_origins=["http://localhost:5173"]` |
